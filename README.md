# Tri de perles

Jeu de tri de perles en pixel art (HTML + JS, sans dépendance), publié sur https://tri-perles.maxteiger.com via GitHub Pages.

Chaque case a un fond de couleur (l'image) mais beaucoup de perles ne sont pas sur le bon fond. Toucher une zone encadrée envoie ses perles mal placées dans les 6 emplacements du bas (9 perles d'une même couleur chacun) ; de là, elles rejoignent seules les cases vides de leur couleur. Emplacements pleins et plus rien à déplacer : perdu. Un emplacement bonus par niveau.

Niveaux : 4 dessins, puis des paysages générés à l'infini. Chaque niveau est vérifié faisable par un bot glouton avant d'être proposé.
